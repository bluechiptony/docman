# Document Types Feature - User Manual & Tutorial Script

## Overview

Document Types allow you to organize and categorize your documents by creating custom types specific to your organization's needs. For example, you might create types like "Invoice," "Contract," "Report," or "Receipt" to make document management more intuitive and structured.

## Accessing Document Types

### Step-by-Step

1. **Log in to DocMan** with your credentials
2. **Navigate to Settings** by clicking your profile menu or settings icon
3. **Select the "Document Types" tab** from the settings navigation

You should now see the Document Types management page.

---

## Viewing Your Document Types

### What You'll See

The Document Types page displays a table with your organization's document types:

- **Name**: The title of your document type (e.g., "Invoice")
- **Description**: Optional details about this type
- **Documents**: Shows how many documents are using this type
- **Created By**: The team member who created this type
- **Actions**: Edit or delete buttons for managing each type

### Empty State

When you first access Document Types, you'll see:

- A friendly message: "No document types yet"
- A suggestion to "Create your first document type to organize your documents"
- An "Add Document Type" button to get started

## Deleting a Document Type

### Important Considerations

⚠️ **Before You Delete:**

- Once deleted, the document type is permanently removed
- Any documents already using this type will remain but may become uncategorized

### When Deletion is Disabled

If a document type has documents assigned to it:

- The delete button (trash icon) will be **disabled**
- You'll see a visual indication it cannot be deleted
- This prevents accidental data loss

### How to Delete

**[Scene: User finds a document type with no documents (Documents count = 0)]**

**Narrator:**

## Best Practices

### ✅ Do's

- **Keep names short and descriptive** (1-3 words): Use "Invoice" instead of "Official Company Invoice Document"
- **Be consistent** with naming: If you use "Invoices," don't also create "Invoice"
- **Add descriptions** to help your team understand the purpose
- **Think about your workflow** before creating types – plan them with your team
- **Test with a few types first** before creating a large number

### ❌ Don'ts

- **Don't create duplicate types** – Check existing types before adding a new one
- **Don't use vague names** like "Document," "File," or "Other"
- **Don't create too many types** – Limit to 10-15 to keep things organized
- **Don't include dates or version numbers** in the name (e.g., "Invoice 2025" or "Report v2")

**Accounting/Finance:**

## Troubleshooting

### "Please log in to manage document types"

**Problem:** You see this message when accessing Document Types.

**Solution:**

- You're not currently logged in, or your session expired
- Log in with your credentials and try again

---

### Delete button is disabled

**Problem:** You want to delete a document type, but the delete button is grayed out.

**Reason:** This document type has documents assigned to it.

**Solution:**

1. Option A: First reassign or delete the documents using this type
2. Option B: Keep the type – it won't hurt to have unused types
3. Contact your administrator if you need help managing documents

---

### "Document type name is required"

**Problem:** You see an error when trying to create a type.

**Solution:**

- The "Name" field is empty
- Enter a name and try again
- The name must be at least 1 character

---

### Changes aren't showing up

**Problem:** You created or edited a document type, but don't see the changes.

**Solution:**

- Wait a moment for the page to refresh
- Try refreshing the page manually (Cmd+R or Ctrl+R)
- Log out and log back in if the issue persists

---

### "Operation failed" error

**Problem:** An error appears when trying to create, edit, or delete.

**Solution:**

- Check your internet connection
- Try again in a few moments
- Contact your system administrator if the error persists
- Note the exact error message to share with support

## Tips & Tricks

### 💡 Pro Tips

1. **Batch organization**: Create your document types all at once before starting to upload documents
2. **Team alignment**: Brief your team on the document types you've created so everyone uses them consistently
3. **Keep it simple**: Start with 5-7 core types and add more only if needed
4. **Document the why**: Use descriptions to explain the business purpose of each type
5. **Review quarterly**: Once a quarter, review your document types to see if any are unused or if new ones are needed

### Using Document Types in Workflows

Once created, use document types:

- **When uploading documents**: Select the appropriate type during upload
- **When searching**: Filter documents by type to find what you need quickly
- **In reports**: Organize reports by document type for better insights
